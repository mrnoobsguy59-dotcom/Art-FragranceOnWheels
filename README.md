# Car Wash & Detail Quote System

This is a lightweight quote calculator for a car wash and detailing business. It helps you respond to customer questions automatically without typing the same message repeatedly.

## Features

- Instant pricing based on vehicle type, size, interior, service level, and condition
- Automatic customer-ready quote messages
- Copy-to-clipboard reply button
- Clear pricing table for your standard rates

## Run locally

Open the project folder in a browser or serve it with a simple web server:

```bash
cd "C:\Users\Timothy\Documents\car-detailing-quote-bot"
py -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customize your prices

Edit the pricing table in `script.js` to match your established rates.
